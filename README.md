# User Authentication API

A RESTful user authentication API built using Node.js, Express.js, MongoDB, Mongoose, and JWT.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Postman

## Features

- User registration
- Password hashing using bcrypt
- User login
- JWT token generation
- Bearer token authentication
- Protected user information route
- Input validation
- Error handling
- MVC architecture
